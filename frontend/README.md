# LessonAI frontend

Next.js 14 + TypeScript + Tailwind. Забонҳо: тоҷикӣ, русӣ, англисӣ.

```bash
cd frontend
cp .env.local.example .env.local     # дар Windows: copy .env.local.example .env.local
npm install
npm run dev
```

Браузерро кушоед: http://localhost:3000 (backend бояд дар http://localhost:8000 кор кунад).

Саҳифаҳо: `/login`, `/register`, `/dashboard`, `/tests/new`, `/tests/[id]`.
